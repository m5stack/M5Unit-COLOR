Detailed Description

Color corrections for 8-bit RGB values (pure hue, brightness normalization, grayscale, color names)

Each function takes an 8-bit RGB value, such as Data::R8() or Calibration::R8(), and returns the corrected color. Pass calibrated values (Calibration) for the best results, so that white and gray have equal channels.

Pure hue.

Removes the white component (the smallest channel) and scales the largest remaining channel to 255. The result is the most saturated color of the same hue (a dull blue becomes a vivid blue). Useful to classify colors by hue regardless of brightness and dullness
